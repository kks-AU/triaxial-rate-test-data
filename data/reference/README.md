# Saved reference curves and stage rates

Generated by `export_reference_curves.m` from the RateEffects MATLAB project.
Each test JSON stores:

- `referenceRate`: saved reference axial strain rate, in %/min. A9 uses the
  configured value, explicitly identified by `referenceRateSource`.
- `rateSequence`: IQR-filtered mean measured axial strain rate for each shear
  stage, in source stage order. Entries contain `stage` and `rate` (%/min).
- `q` / `qp`: sampled saved PCHIP curves (`strain` in %, `values` in kPa for q
  and dimensionless for q/p′). Sampling includes 1,200 evenly spaced points,
  every reference control point and the saved reference peak. Only the supported
  strain interval is evaluated; there is no extrapolation. A9 has empty curves.
- `sourceShearSHA256` / `sourceReferenceSHA256`: hashes of the saved input MAT
  files. The exporter checks that the shear file matches the public manifest
  and validates the saved reference source fingerprint.

Each stage's measured rate is calculated by removing values outside
[Q25 − 1.5 IQR, Q75 + 1.5 IQR], then taking the finite mean, as in the source
processing. All stages are retained, including stages without an analysed rate
jump. Rates for analysed jumps are checked against both `RateBefore` and
`RateAfter`. These measured rates are not nominal actuator commands.

`build-preview.mjs` copies these data into each plotting JSON and adds reference
rate, availability and stage sequence to the catalogue. The measured shear plot
uses a separate q/p′ column derived from the exported processed q and p′;
reference curves are never inferred from those reduced plotting points.
