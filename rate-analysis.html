Definitions and fitting method

rstep = rate after / rate before; rref = rate after / reference rate. Step departures subtract the preceding stage’s final averaged reference departure. qmax,ref is the saved reference-trajectory maximum. For step normalization, q₀ and (q/p′)₀ are the preceding stage’s final averaged measured values. For reference normalization, they are the reference values at the response strain.

Trendlines use y = c log₁₀(r), constrained through (1, 0), with separate pre- and post-peak fits. Beta uses the source analysis’s iterative 3.5-MAD residual rejection; other coefficients use ordinary least squares. All finite fits are displayed; R² below 0.70 is marked as a low fit. R² = 1 − SSE / Σ(y − mean(y))² and can be negative. Reference-rate stages are excluded from reference sensitivity. No fit is available with fewer than two valid points.

The γ-versus-strain plots show |Δq/qmax,ref| / |log₁₀(r)| at each maximum or endpoint. Their exported γ fits use the signed normalized response against log₁₀(r). End-coefficient fits use only endpoints that passed the saved persistence test. Nonpersistent endpoints remain visible as crosses. γqp here is normalized by (q/p′)₀, as specified in the plot axes.

The existing K1 analysis uses R = σ′v/σ′h = (3 + 2q/p′)/(3 − q/p′) and an estimated plastic-strain coordinate. Its reference is still evaluated at equal total strain. The K1 q-state plot therefore retains the total-strain q response, with estimated plastic strain available on hover. R maxima are recalculated in R space. Plastic strain is clipped to zero and made nondecreasing using the initial tangent estimate; this is not an equal-plastic-strain reference reconstruction.
