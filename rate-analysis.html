What do β and γ mean?

Both describe sensitivity per tenfold change in strain rate. β normalizes the stress response by q₀; γmax/end normalizes it by qmax,ref. A fitted coefficient of 0.03 corresponds to a response of 3% of its normalization quantity when r = 10.

β · stress-state normalization

Δqstep,max / q₀ = βstep log₁₀(rstep)
Δqref,max / q₀ = βref log₁₀(rref)

β is the fitted slope. For step response, q₀ is the preceding stage’s final averaged q. For reference response, q₀ is the reference-curve q at the maximum-response strain.

γmax/end · reference-peak normalization

γt,a = |Δqa,t / qmax,ref| / |log₁₀(ra)|

This is the individual value plotted against strain, where a = step or ref and t = max or end. qmax,ref is the maximum of the reference q trajectory.

The downloadable fitted γ is instead the slope in Δqa,t / qmax,ref = γt,a,fit log₁₀(ra), using signed departures across stages. It is not the mean of the plotted magnitudes.

γqp · normalized q/p′ sensitivity

Δ(q/p′)a,max / (q/p′)₀ = γqp,a log₁₀(ra)

γqp,step and γqp,ref are fitted slopes, with a = step or ref. (q/p′)₀ follows the same preceding-stage / reference-curve convention as q₀.

γR · existing K1 R sensitivity

ΔRmax / R₀ = γR,step log₁₀(rstep)

R = σ′v/σ′h; R₀ is the preceding stage’s final averaged R. γR,step is the fitted slope. The existing K1 plastic analysis retains its total-strain reference.

rstep = rate after / rate before · rref = rate after / reference rate. “max” denotes the saved directional maximum after the rate change; “end” denotes the stage endpoint. Δ is signed in the response plots and fitted models. Coefficients are dimensionless per decade of rate.

Rate-ratio groups, reference definitions and fitting method

Δ-response plots separate approximate rate-ratio groups by marker shape: step groups ≈ 0.2, 0.5 and 10; reference groups ≈ 0.2, 1 and 2. Filled markers are pre-peak and open markers are post-peak. A measured ratio is grouped only within 50% of a group value; overlaps use the nearest group in log space. Remaining ratios are labelled “Other”. These are display groups, not commanded-rate values. Hover labels and CSV downloads retain measured ratios; fits always use measured ratios across groups, separately for each specimen and peak branch.

rstep = rate after / rate before; rref = rate after / reference rate. Step departures subtract the preceding stage’s final averaged reference departure. qmax,ref is the saved reference-trajectory maximum. For step normalization, q₀ and (q/p′)₀ are the preceding stage’s final averaged measured values. For reference normalization, they are the reference values at the response strain.

Trendlines use y = c log₁₀(r), constrained through (1, 0), with separate pre- and post-peak fits. Beta uses the source analysis’s iterative 3.5-MAD residual rejection; other coefficients use ordinary least squares. All finite fits are displayed; R² below 0.70 is marked as a low fit. R² = 1 − SSE / Σ(y − mean(y))² and can be negative. Reference-rate stages are excluded from reference sensitivity. No fit is available with fewer than two valid points.

The γ-versus-strain plots show |Δq/qmax,ref| / |log₁₀(r)| at each maximum or endpoint. Their exported γ fits use the signed normalized response against log₁₀(r). End-coefficient fits use only endpoints that passed the saved persistence test. Nonpersistent endpoints remain visible as crosses. γqp here is normalized by (q/p′)₀, as specified in the plot axes.

The existing K1 analysis uses R = σ′v/σ′h = (3 + 2q/p′)/(3 − q/p′) and an estimated plastic-strain coordinate. Its reference is still evaluated at equal total strain. The K1 q-state plot therefore retains the total-strain q response, with estimated plastic strain available on hover. R maxima are recalculated in R space. Plastic strain is clipped to zero and made nondecreasing using the initial tangent estimate; this is not an equal-plastic-strain reference reconstruction.
